LAST COUNTY — STAGE 32

Este é um pacote de atualização para a pasta main.

INSTALAÇÃO
1. Faça uma cópia de segurança da sua pasta main atual.
2. Extraia o conteúdo deste ZIP diretamente dentro da pasta main.
3. Confirme a substituição dos arquivos quando solicitado.
4. Abra o jogo normalmente pelo index.html ou pelo servidor que você já utiliza.

O ZIP não possui uma pasta externa envolvendo os arquivos.

CONTROLES CRIATIVOS
P   abre o catálogo
Z   liga/desliga o voo
Esc abre o menu
Clique esquerdo remove
Clique direito coloca

Os saves de Sobrevivência e Modo Criativo são independentes.
